# カード画像フォルダ（任意・自分用）

公式のカードイラストには著作権があります。
このフォルダの画像を GitHub / Netlify など公開場所に上げないでください。
他の攻略サイトから画像をコピーして置くのも転載になるのでやめましょう。

## 既定の表示

サイト側ではカード絵を出しません（偽画像も出しません）。

## 自分のPCだけで置きたいとき

1. 設定タブで「ローカル画像フォルダがあるときだけ表示する」をONにして保存
2. ここにファイルを置く（例: c001.webp / c001.png / c001.jpg）
