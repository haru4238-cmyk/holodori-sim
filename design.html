HOLODORI SIM 設計図（サイト版）

このページは「サイトとして公開するアプリ」の説明書です。詳細データは design.json にあります。バージョン 3.3.0。

サイトとして使うには？

  1. いちばん簡単：フォルダの index.html をダブルクリック
  2. Netlify Drop：フォルダをドラッグ
  3. GitHub Pages：GitHubに置いて Pages をON
  4. 自分のPCサーバー：python -m http.server 8080

表示が古いときは Ctrl+F5 で強制再読み込みしてください。

ホロメンボード（任意）

  • やらなくてもOK
  • 正確な全マス図が未公開なので、推測のマス図は出さない
  • 実機を見て効果％・配置メモを登録
  • 「ボード共有JSON」で友達とマージ → みんなで正確化
  • サーバには送らない（端末内のみ）

カード画像

公式絵の同梱・他サイトからの転載表示・偽サムネはしません。自分のPCの images/ に置く場合だけ任意表示。

セキュリティ

  • 入力データはあなたの端末の中だけ（localStorage）
  • 外部へ勝手に送信しない
  • CSPで怪しいスクリプトをブロック
  • バックアップJSONは他人に渡さない（ボード共有JSONは効果メモの共有用）
